# KJD Edit
iPad-first audio editor with Pro Tools-style layout and key commands (KJD Productions).
Open the GitHub Pages URL in Safari on iPad → Share → Add to Home Screen. Works offline after the first open.

Built-in piano samples: from the tonejs-instruments piano set (npm `tonejs-instrument-piano-mp3`, MIT). FLAC packing: libflac.js (MIT). Screen view: noVNC (MPL-2.0).
